## basics
- Esc to go into Normal mode. if any accident.


## search(and highlight) & replace
`vim hello.txt`
`ESC`
`:%s/hello/goodbye/g`

```
`esc` to be sure to be in normal mode
: a command.
% - everything in this file.
s - sub(basicaly replace)
/hello/goodbye - replace 'hello' with 'goodbye'
/g - global(even in same line multiple occurences)
```
